Unified Load Board — daily checklist (extension mode)
=====================================================
1. SILENT_START / Task Scheduler starts serve_board.py only (NO CDP Chrome by default).
2. Normal Chrome stays open with the Unified Load Board Scanner extension installed.
3. One-time: sign into Arrive / RXO / ArcBest / Echo / CHR via extension popup → Open.
4. Open board http://localhost:8765/ — banner shows “Extension mode” when data was POSTed by the extension.
5. Empty / logged-out sources keep last-good loads; popup shows per-broker status.
6. Download/install help is on the board (“Download / Install extension”) and EXTENSION.md.
7. Legacy CDP: only if ULB_ENABLE_CDP=1 — not needed for daily use.
